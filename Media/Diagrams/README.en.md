# Ultimate Puzzles Dinos Visual Pack

[English](README.en.md) | [Español](README.md)

Planned images for the **Ultimate Puzzles Dinos** project.

This directory is prepared to include the project's visual assets in original and web-optimized versions.

### original-png/

- `ultimatepuzzlesdinos-logo.png`
- `ultimatepuzzlesdinos-cover.png`
- `ultimatepuzzlesdinos-banner.png`
- `ultimatepuzzlesdinos-thumbnail-01-puzzle-selection.png`
- `ultimatepuzzlesdinos-thumbnail-02-dino-puzzle.png`
- `ultimatepuzzlesdinos-thumbnail-03-solution-validation.png`
- `ultimatepuzzlesdinos-thumbnail-04-level-progression.png`

## Recommended usage

- `ultimatepuzzlesdinos-logo.webp` for project identity.
- `ultimatepuzzlesdinos-cover.webp` for Open Graph, cover and social sharing.
- `ultimatepuzzlesdinos-banner.webp` for the portfolio website.
- Thumbnails for cards, documentation, README files or technical previews.
