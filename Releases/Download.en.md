- 2D top-down view and UI-based gameplay.
- More than 50 levels.
- Piece selection, drag and drop.
- Solution validation.
- Level system and planned unlocking.
- Main menu, level menu, sound and music.
- Preparation for Ads, IAP, Analytics and Google Play Store publication.

## How to run or install

1. Open the GitHub Releases page linked above.
2. Download the Android file available in the **Assets** section.
